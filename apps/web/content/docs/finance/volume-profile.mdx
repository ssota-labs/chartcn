## A histogram turned sideways

Every other mark here runs along the time axis. This one runs along the price
axis: volume is bucketed by price and drawn as horizontal bars anchored to the
right gutter.

It is also the only thing in the engine recomputed on every frame. Everything
else — moving averages, RSI, the cloud — is derived once from the whole series,
because deriving from the visible slice would change the answer as you scroll.
Here changing with the window *is* the answer: the profile describes what is on
screen, so panning genuinely gives a different histogram.

## Shared engine

the marks the other charts use were not enough to express it honestly.
