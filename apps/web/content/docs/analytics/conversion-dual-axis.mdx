## Data shape

```ts
type ConversionPoint = {
  month: string
  conversions: number // absolute volume (left axis)
  rate: number // percent (right axis)
}
```

Bind volume to `yAxisId="left"` (`Bar`) and rate to `yAxisId="right"` (`Line`).
