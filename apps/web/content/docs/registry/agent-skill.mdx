The skill lives at `.agents/skills/chartcn/SKILL.md`.

It covers:

1. **Variant decision table** — when to use area vs bar vs line vs stubs  
2. **Data shapes** for foundation items  
3. **Install** via `npx shadcn@latest add https://<CHARTCN_REGISTRY_HOST>/r/<name>.json`  
4. **Server MDX / RSC** insertion  
5. **Client json-render** component map (`registry item → JSON node type`)

Typical agent loop:

```text
pnpm chartcn-search <need> --json
  → pick ready item
  → shadcn add <host>/r/<name>.json
  → MDX component or json-render map entry
```

See also [MDX embedding](/docs/registry/mdx-embedding) and [json-render](/docs/registry/json-render).
