## Pattern

1. Install (or use the demo export) `chart-area-stacked`  
2. Register the client component in `getMDXComponents`  
3. Use the JSX tag in MDX

```tsx
import { ChartAreaStacked } from "@/components/charts"

export function getMDXComponents(components) {
  return {
    ...defaultMdxComponents,
    ChartAreaStacked,
    ...components,
  }
}
```

```mdx
## Mix over time

```
