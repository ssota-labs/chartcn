Each chart variant is a **shadcn registry item**. Install with the official CLI — sources are `ChartContainer` + Recharts.

## Install

Set the host:

```bash
export CHARTCN_REGISTRY_URL=https://<CHARTCN_REGISTRY_HOST>
# or locally:
export CHARTCN_REGISTRY_URL=http://localhost:3000
```

Then:

```bash
# base primitives
npx shadcn@latest add chart card

# any variant
npx shadcn@latest add https://<CHARTCN_REGISTRY_HOST>/r/chart-area-basic.json
npx shadcn@latest add $CHARTCN_REGISTRY_URL/r/chart-area-stacked.json
npx shadcn@latest add $CHARTCN_REGISTRY_URL/r/chart-bar-grouped.json
npx shadcn@latest add $CHARTCN_REGISTRY_URL/r/chart-line-multi.json
```

Local routes: `GET /r/<name>.json` and `GET /r/registry.json`.

## Naming

Variants follow `chart-<family>-<variant>` (for example `chart-area-stacked-expand`).

See [Installation](/docs/registry/installation), [Search CLI](/docs/registry/search-cli), [Agent skill](/docs/registry/agent-skill), [MDX embedding](/docs/registry/mdx-embedding), and [json-render](/docs/registry/json-render).
